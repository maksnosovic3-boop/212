## User Interface

Open `index.html` in a browser to view the accessible user interface.

The page follows [WCAG 2.1 AA](https://www.w3.org/WAI/WCAG21/quickref/) guidelines:

- Semantic HTML5 landmarks (`<header>`, `<main>`, `<footer>`)
- Skip-navigation link for keyboard users
- Visible focus indicators (`outline` on `:focus-visible`)
- Sufficient colour contrast (≥ 4.5 : 1 for normal text)
- `aria-label` and `aria-labelledby` on all interactive sections
